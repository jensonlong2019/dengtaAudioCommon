# 灯塔公共媒体库

公共音频共享仓库，对应灯塔应用的「公共音频 → 同步远端」。

## 使用

1. 在应用的公共音频页导入本地音频，或从视频合成对白存入公共库。
2. 点击「同步远端」，上传本地新增音频并下载远端新增音频。
3. 另一台电脑点击同一按钮即可使用，重复同步不会重复入库。

单端改名会同步；两端同时改成不同名称时提示冲突。本地删除暂不删除远端，下次同步也不自动恢复该条目。已插入视频合成任务的音频是独立拷贝。

## 目录与扩展

- `audio/`：当前公共音频，支持 WAV、MP3、M4A、FLAC、OGG。
- `video/`：预留独立公共视频资源。
- `mp3/`：预留独立公共 MP3 分类，现有公共音频中的 MP3 仍属于 audio。
- `manifest.json`：公共媒体清单，`kind=shared-media-library`、`schemaVersion=1`。

音频条目使用稳定 `id`、`mediaType=audio`、名称、`filePath=audio/{id}/audio.{ext}`、contentType、sizeBytes、durationSeconds 与 SHA-256。未来的 video/mp3 类型由当前音频同步原样保留。

建议通过应用同步发布资源；仅放文件而未登记清单的音频不会自动下载。单音频须小于 100 MiB，当前不使用 Git LFS。

## Git 凭据

应用先使用 HTTPS；推送认证失败时尝试同一仓库的现有 OpenSSH 凭据。GitHub 主机必须已在本机信任，操作不会弹出终端密码输入，也不会修改 Git 配置。Plink 等变体请改用 OpenSSH 或配置 HTTPS 凭据。

仓库只保存公共资源和清单，不保存应用数据库、绝对路径、项目数据或身份凭据。
